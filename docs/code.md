## pet/core/src/protocol.rs
**protocol:**

- framing
- signing and keys
- challenges
- hex

- `const HEADER: [u8; 4] = [0xFF; 4];`: quake oob header
- `pub const VERSION: u8 = 1;`: protocol version, outdated clients get dropped
- `pub const PORT: u16 = 27960;`: we're doing quake already so lets reuse the port aswell
- `pub const MAX_PACKET: usize = 1200;`: prevents fragments, 1200 fits common mtus
- `const UNSIGNED_REQUEST_SIZE: usize = 128;`: unsigned asks get padded, so answers are never bigger (no amplification)
- `const ACCOUNT_SECRET_LABEL: &[u8] = b"pet account v1";`: *insert salt bae gif*
- `pub enum Request`: a sync sends the revision it has, so an unchanged world isnt sent again
- `Refused`: carries the world so wrong guesses get fixed
- `pub fn decode(bytes: &[u8]) -> Option<Packet>`: leftover bytes mean junk, so they fail
- `pub fn tag(bytes: &[u8]) -> Option<&[u8]>`: same tag = same request
- `pub fn unverified(bytes: &[u8]) -> Option<Packet>`: find account
- `pub fn challenge(secret: &Secret, address: SocketAddr, minute: u64) -> Challenge`: proves the sender receives packets at specified address, trimmed to 16 bytes
- `pub fn from_hex<const N: usize>(text: &str) -> Option<[u8; N]>`: prevent non-ascii panic

## pet/server/src/main.rs
**pet server:**

- flags and startup
- udp loop
- signups and logins
- commands and syncs

- `const SAVE_CAUGHT_UP_AFTER: Duration = Duration::from_secs(60);`: prevent saving to db on every single sync (~4/sec)
- `fn challenge_fits(&self, challenge: &Challenge, from: SocketAddr) -> bool`: we trust the previous minute so time passed between send and parse doesn't invalidate the challenge
- `fn command(`: stored reply first, so a retry works even after the sequence moved on. cheats require server in dev mode, no privileged users
- `fn sync(&self, account: &AccountId, since: Option<u64>, from: SocketAddr) -> Option<Reply>`: no sequence check, two terminals syncing at once is fine
- `fn unsigned(packet: Packet, request: &[u8], from: SocketAddr) -> Option<Vec<u8>>`: reply can never be bigger than request to prevent amplification
- `fn logged<T>(result: std::result::Result<T, impl Display>, what: &str) -> Option<T>`: db error drops packet, server doesnt panic
